# Горячие клавиши

Все сочетания назначены стандартными средствами Qt
(`QKeySequence`) и работают одинаково на Windows и Linux.

## Файл

| Сочетание | Действие                                   |
| --------- | ------------------------------------------ |
| `Ctrl+O`  | Открыть файл / несколько файлов            |
| `Ctrl+Shift+O` | Открыть папку (все PDF рекурсивно)    |
| `Ctrl+S`  | Сохранить результат текущего задания       |
| `Ctrl+E`  | Экспорт в DOCX / TXT                       |
| `Ctrl+Q`  | Выход                                      |

## Очередь и запуск

| Сочетание | Действие                                   |
| --------- | ------------------------------------------ |
| `Ctrl+R`  | Запустить / возобновить обработку очереди  |
| `Ctrl+.`  | Остановить текущую обработку (soft)        |
| `Delete`  | Удалить выбранную строку из очереди        |

## Профили

| Сочетание | Действие                                   |
| --------- | ------------------------------------------ |
| `Ctrl+1`  | Профиль «Универсальный»                    |
| `Ctrl+2`  | Профиль «Скан книг»                        |
| `Ctrl+3`  | Профиль «Плохой скан»                      |
| `Ctrl+4`  | Профиль «Рукописный» (HTR)                 |

## Вид

| Сочетание | Действие                                            |
| --------- | --------------------------------------------------- |
| `Ctrl+H`  | Показать/скрыть bbox-подсветку распознанных слов    |
| `Ctrl+F`  | Найти в тексте результата                           |
| `Esc`     | Закрыть панель поиска / модальный диалог            |
| `F11`     | Полный экран                                        |

## Настройки и справка

| Сочетание | Действие                              |
| --------- | ------------------------------------- |
| `Ctrl+,`  | Настройки приложения                  |
| `F1`      | О программе                           |
| `Ctrl+L`  | Открыть лог-файл                      |

## Навигация по PDF

| Сочетание        | Действие                             |
| ---------------- | ------------------------------------ |
| `PgDn` / `PgUp`  | Следующая / предыдущая страница      |
| `Ctrl++`         | Увеличить масштаб                    |
| `Ctrl+-`         | Уменьшить масштаб                    |
| `Ctrl+0`         | Масштаб 100%                         |

## Постобработка

| Сочетание | Действие                              |
| --------- | ------------------------------------- |
| `Ctrl+N`  | Добавить пустое регексп-правило       |

## Советы

- Сочетания можно кастомизировать только через Qt-редактор
  `~/.config/OCRStudio/shortcuts.json` (план на будущее — редактор
  в диалоге «Настройки»).
- В полях ввода (`QLineEdit`, `QTextEdit`) стандартные shortcut'ы
  Qt имеют приоритет — `Ctrl+F` в текстовом поле не сработает,
  пока фокус в нём.
