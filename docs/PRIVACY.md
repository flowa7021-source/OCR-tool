# Privacy & Data Storage

OCR Studio — **полностью локальное** desktop-приложение. Ни скан,
ни его распознанный текст никогда не покидают машину пользователя.

## Что хранится и где

| Тип данных            | Путь (Windows)                                       | Назначение                                          |
| --------------------- | ---------------------------------------------------- | --------------------------------------------------- |
| Пользовательские настройки | `%LOCALAPPDATA%\OCRStudio\config\settings.json` | Тема, число воркеров, последние файлы               |
| Профили обработки     | `%LOCALAPPDATA%\OCRStudio\config\profiles\*.json`    | Ваши кастомные и копии встроенных профилей          |
| Лог-файл              | `%LOCALAPPDATA%\OCRStudio\logs\ocr-studio.log`       | Rotating 5 × 5 MB — только диагностика, без текста  |
| Временные PNG         | `%LOCALAPPDATA%\OCRStudio\temp\job_*/`               | Промежуточные растры; удаляются на выходе           |
| Recovery-снапшоты     | `%LOCALAPPDATA%\OCRStudio\recovery\*.json`           | Для возобновления прерванных заданий (тексты страниц) |
| Кэш моделей HTR       | `%LOCALAPPDATA%\OCRStudio\models\GOT-OCR-2.0\`       | Загруженные веса (~4 GB) — управляются меню         |

На Linux пути аналогичны через `~/.local/share/OCRStudio/`.
На macOS — `~/Library/Application Support/OCRStudio/`.

## Сетевые обращения

Приложение делает **только три вида HTTP-запросов** и все три —
опциональные, только по явной команде пользователя:

1. **`Справка → Проверить обновления`** — одиночный GET на
   `api.github.com/repos/.../releases/latest`. Передаётся только
   стандартный `User-Agent: OCRStudio/<version>`.
2. **`Движок OCR → Скачать GOT-OCR 2.0`** — потоковая загрузка
   весов с Hugging Face Hub (URL проверяется перед записью на диск).
3. **OCRmyPDF-обновления языковых данных** (`.traineddata`) —
   не выполняется автоматически. Нужны только для языков, отсутствующих
   в поставке; добавляются пользователем вручную.

Никакой аналитики, телеметрии, crash-reporting'а на чужие серверы
приложение не выполняет.

## Diagnostics bundle

`Справка → Экспорт диагностики…` собирает zip со следующим содержимым:

- хвост лог-файла (последние 2 MB);
- `settings.json` и список имён профилей **без содержимого
  регексп-правил** — чтобы не утекли бизнес-правила;
- версии Python, Qt, Tesseract, OS.

Содержимое ваших документов / распознанного текста **никогда** не
попадает в диагностический архив. Файл сохраняется строго туда,
куда вы его укажете через файловый диалог.

## Что удаляет деинсталлятор

Inno Setup по умолчанию удаляет только установочный каталог
(`Program Files\OCR Studio`). Чекбокс «Удалить пользовательские
данные» (снят по умолчанию) доплняет удаление каталогом
`%LOCALAPPDATA%\OCRStudio\`.

Если вы хотите очистить данные вручную — удалите указанный
каталог (операция обратима только из бэкапа).

## Рекомендация для корпоративных пользователей

- Если ваша политика запрещает любое сетевое общение, отключите
  проверку обновлений в `Настройки → Общие` и не скачивайте HTR-веса.
- Логи не содержат текста документов, но содержат имена файлов —
  если это sensitive, очистите папку `logs/` перед передачей
  диагностического архива.
