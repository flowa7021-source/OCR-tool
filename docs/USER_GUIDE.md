# Руководство пользователя

Пошаговая инструкция для первого распознавания. Весь UI — на
русском языке.

## 1. Установка

1. Скачайте `OCR-Studio-Setup-x.y.z.exe` из раздела Releases.
2. Запустите установщик (требует прав администратора для `Program Files`;
   без них установщик можно запустить «как текущий пользователь»).
3. Мастер Inno Setup выполнит распаковку, зарегистрирует ярлыки в меню
   «Пуск» и при желании свяжет `.pdf` как тип файла по умолчанию.
4. При первом запуске приложение создаст следующие каталоги:
   - `%LOCALAPPDATA%\OCRStudio\config\` — настройки и профили;
   - `%LOCALAPPDATA%\OCRStudio\logs\` — лог-файл (rotating 5×5 МБ);
   - `%LOCALAPPDATA%\OCRStudio\temp\` — промежуточные PNG (удаляется
     при выходе и при следующем запуске, если старее 24 ч).

## 2. Проверка Tesseract

На старте приложение вызывает `tesseract --version`. Если проверка
не проходит, вы увидите предупреждение — OCR не сможет работать,
пока Tesseract 5.x не окажется в `PATH` либо не будет положен рядом
с исполняемым файлом (`_internal/tesseract-bin/tesseract.exe`).

## 3. Первое распознавание

1. **Перетащите** PDF-файл (или несколько) в главное окно **или**
   нажмите `Файл → Открыть…` / `Ctrl+O`.
2. Файл появится в очереди слева. Выбор строки показывает превью
   скана в центре и активирует панели настроек справа.
3. В вкладке **Профиль** выберите один из встроенных шаблонов:
   - **`universal_accurate`** — максимальная точность, включает все
     шаги предобработки (deskew + CLAHE + удаление фона + adaptive
     Gaussian бинаризация + многошаговый denoise), 600 DPI и вся
     постобработка. Выбирается при первом запуске. Рекомендуется как
     первый вариант; для больших PDF работает дольше из-за 600 DPI,
     для быстрой обработки используйте `default` (300 DPI).
   - `default` — сбалансированные настройки (OTSU, однократный median).
     Быстрее, но менее устойчив к неравномерному освещению.
   - `low_quality_scan` — агрессивный NLM-denoise + CLAHE clip=4.0 для
     плохих сканов.
   - `contracts_ru` — минимум обработки, PSM=SINGLE_BLOCK для
     однородного текста.
   - `english_text` — только английский, лёгкая предобработка.
   - `handwritten_mixed` — использует GOT-OCR 2.0 (требует загрузки весов).
4. Нажмите кнопку **«Запустить»** на тулбаре (или `Ctrl+R`).
5. Прогресс-бар снизу покажет ETA, текущую страницу и номер файла.

## 4. Что получится на выходе

- **PDF/A**-файл с прозрачным текстовым слоем — то же имя, суффикс
  `_ocr` (можно изменить в «Настройках вывода»).
- Опционально: `.txt`, `.docx` — выбираются чекбоксами в профиле.
- Переключатель **«Подсветить распознанный текст» (`Ctrl+H`)**
  рисует bounding-box'ы слов цветом по уровню confidence (зелёный —
  высокий, красный — низкий).

## 5. Проверка и правка результата

Правая панель **«Результаты»** содержит текст по страницам.
Поддерживается:

- `Ctrl+F` — поиск по странице с подсветкой всех вхождений и
  счётчиком;
- кнопка «Сохранить PDF как…» — позволяет выбрать новое место;
- селектор кодировки — UTF-8 по умолчанию, UTF-8 BOM / Windows-1251
  для Microsoft Word.

## 6. Профили и горячие переключатели

- `Профиль → Сохранить как…` — сохранить текущие настройки под новым
  именем (создаёт JSON в `config/profiles/`).
- `Ctrl+1 … Ctrl+4` — быстрое переключение между первыми четырьмя
  встроенными профилями.
- «Импорт / экспорт» — разделите свой профиль с коллегой одним JSON.

## 7. Пакетная обработка

- Перетащите **папку** с PDF — все файлы будут добавлены в очередь.
- В настройках (`Ctrl+,`) задайте число параллельных воркеров
  (рекомендовано 2–4 в зависимости от CPU).
- Фильтр в верхней части очереди позволяет отобрать файлы по имени
  «на лету».
- Правый клик по строке → «Повторить» / «Открыть папку с результатом».

## 8. Работа с рукописным текстом (HTR)

1. **Если установлен HTR-инсталлятор** (файл `OCR-Studio-Setup-*.exe`
   размером ~800 МБ): веса GOT-OCR 2.0 уже на диске — достаточно
   выбрать профиль `handwritten_mixed` либо переключить
   «Движок = GOT-OCR 2.0» в настройках. Никакого скачивания.
2. **Если нет**: меню `Движок OCR → Скачать GOT-OCR 2.0 (рукописный)`
   запустит разовую загрузку ~580 МБ с HuggingFace в
   `%LOCALAPPDATA%\OCRStudio\models\`.
3. Первый запуск инициализирует модель (10–30 с), далее работает
   быстрее. GPU используется автоматически, если доступен CUDA;
   иначе CPU (в разы медленнее, но работает).

## 9. Тема оформления

- `Вид → Светлая тема` — мгновенное переключение без перезапуска.
- `Настройки → Интерфейс` — то же самое с сохранением выбора.

## 10. Перенос конфигурации между машинами

- `Файл → Экспорт конфигурации…` — сохранит `settings.json` и все
  пользовательские профили в один ZIP. Встроенные профили не
  экспортируются — они едут в составе установщика.
- `Файл → Импорт конфигурации…` — восстановит всё из ZIP на новой
  машине. При совпадении имён пользовательские профили перезаписываются
  (после подтверждения). Тема применяется сразу.
- Уведомления о завершении задания (системный трей) включаются в
  `Настройки → Уведомление при завершении задания`. Toast появляется
  только если главное окно не в фокусе — внутри приложения прогресс
  и так виден.

## 11. Если что-то пошло не так

- `Справка → Открыть лог-файл` — показывает последние записи с
  уровнем, временем и стеком ошибок.
- `Справка → Экспорт диагностики…` — соберёт zip с логом, конфигом,
  списком профилей и системной информацией (без содержимого
  ваших документов) — полезно для bug-репортов.
- Нажмите `F1`, чтобы открыть «О программе» с версиями Python, Qt,
  Tesseract.
